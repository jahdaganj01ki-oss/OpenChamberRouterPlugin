# VS Code Extensions mit kostenlosen KI-Modellen (ohne API-Key)

Basierend auf einer tiefgehenden Recherche wurden die folgenden VS Code Extensions identifiziert, die kostenlose KI-Modelle oder APIs ohne API-Key-Anforderung bereitstellen.

## 🚀 Top Extensions mit kostenlosen Modellen

### 1. **alphacode** (dragonked2/alphacode)
- **Beschreibung**: Kostenfreie MIT AI-Coding-Agent – keine API-Key-Anforderung. Eingebautes kostenloses Modell oder alternativ Claude, GPT, Gemini, DeepSeek, Ollama +50 weitere. Swarm-Modus, 40+ Tools, Browser- und Desktop-Automatisierung, in Rust implementiert.
- **Typ**: Lokal/Offline
- **Modelle**: Eingebautes kostenloses Modell + 50+ Optionen

### 2. **OmniCopilot** (diegosouzapw/OmniCopilot)
- **Beschreibung**: 1200+ AI-Modelle in Ihrem GitHub Copilot Chat – kostenlos & für immer kostenlos. VS Code Extension, powered by OmniRoute: 340+ Provider (90+ kostenlos) – Kimi, Claude, GPT, Gemini, GLM, DeepSeek, Qwen – mit Agent Mode, Tool Calling, Vision und quota-aware auto-fallback.
- **Typ**: Cloud-basiert (mit kostenlosen Providern)
- **Modelle**: Kimi, Claude, GPT, Gemini, GLM, DeepSeek, Qwen + weitere

### 3. **FreeCoder** (Hybridash/FreeCoder)
- **Beschreibung**: Kostenfreie AI-Coding-Agent-Extension für VS Code, die Dateien liest, durchsucht und editiert. Läuft auf Gemini's kostenloser API, Groq, OpenRouter kostenlosen Modellen oder Ollama.
- **Typ**: Cloud + Lokal
- **Modelle**: Gemini (kostenlos), Groq, OpenRouter, Ollama

### 4. **ace-codex** (teeeteee23/ace-codex)
- **Beschreibung**: AI-gestützte VS Code Extension mit lokalen Ollama-Modellen für Inline-Code-Vervollständigung – eine kostenlose GitHub Copilot-Alternative.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modelle)

### 9. **Vs-Code-Extension** (jayzalani/Vs-Code-Extension)
- **Beschreibung**: Kostenfreie, KI-gestützte lokale Assistent für VS Code. Starke Alternative zu GitHub Copilot und DeepSeek. Bietet DeepSeek-Funktionalitäten ohne die damit verbundenen Datenschutzbedenken.
- **Typ**: Lokal/Offline
- **Modelle**: Lokale Modelle

### 10. **onthereg-vscode-extension** (woodsai69rme/onthereg-vscode-extension)
- **Beschreibung**: OnTheReg VS Code Extension – KI-gestützte Codegenerierung mit OpenRouter kostenlosen Modellen.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter kostenlose Modelle

## 🏠 Lokale/Offline-Extensions (keine Cloud, keine API-Keys)

### 1. **andès** (aqerd/andes)
- **Beschreibung**: VS Code Extension mit Unterstützung für Ollama lokale Modelle in der Benutzeroberfläche.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modelle)

### 2. **OmniChat-VSCode-Extension** (VaidikV/OmniChat-VSCode-Extension)
- **Beschreibung**: Datenschutzfreundliche VS Code Extension, die mit jedem lokalen LLM über Ollama kommuniziert. Chatten Sie mit KI-Modellen direkt in Ihrem Editor, ohne Daten in die Cloud zu senden.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modelle)

### 3. **Autocomplete-VsCode-Ollama** (gijs-d/Autocomplete-VsCode-Ollama)
- **Beschreibung**: VS Code Extension mit Code-Vervollständigungsvorschlägen in der Standardschnellauswahl, gesteuert von einem lokalen Ollama-Server. Keine externen Cloud-Dienste erforderlich.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modelle)

### 4. **local-completion** (TheXnator/local-completion)
- **Beschreibung**: Inline-Vervollständigung für VS Code mit lokalen Modellen über Ollama.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modellen)

### 5. **VSCode-AI-Autocomplete** (proud-commerce/VSCode-AI-Autocomplete)
- **Beschreibung**: Leichte VS Code Extension mit KI-gestützten Code-Vervollständigungen mit lokalen LLM-Modellen (Ollama, LM Studio) oder Remote-APIs (GPT, Claude, Gemini, Mistral).
- **Typ**: Lokal/Offline + Cloud
- **Modelle**: Ollama, LM Studio (lokal) + GPT, Claude, Gemini, Mistral (Remote)

### 6. **VSCode-Local-Copilot** (TheUnknown550/VSCode-Local-Copilot)
- **Beschreibung**: VS Code Extension mit GitHub-Copilot-ähnlicher Funktionalität mit lokal laufenden Ollama-Modellen.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama (lokale Modelle)

### 7. **VSCode-Local-LLM-Chat** (karthik4621r/vscode-local-llm-chat)
- **Beschreibung**: VS Code Extension, die es ermöglicht, lokale LLM-Modelle zu installieren und mit Ollama direkt vom Terminal zu chatten.
- **Typ**: Lokal/Offene
- **Modelle**: Ollama (lokale Modelle)

### 8. **vscode-local-llm** (aymenamaraa/vscode-local-llm)
- **Beschreibung**: Claude Code-ähnlicher AI-Coding-Agent für VS Code, angetrieben von lokalen Modellen (Ollama, LM Studio, OpenAI-kompatibel).
- **Typ**: Lokal/Offline
- **Modelle**: Ollama, LM Studio (lokale Modelle)

### 9. **Smile-ai** (harshmriduhash/Smile-ai)
- **Beschreibung**: Leistungsstarker Code-Assistent für VSCode mit völlig lokalen KI-Modellen. Ähnelt Cursor mit umfassenden Funktionen, funktioniert ohne Internetverbindung mit lokalen AI-Modellen (Ollama, LM Studio).
- **Typ**: Lokal/Offline
- **Modelle**: Ollama, LM Studio (lokale Modelle)

### 10. **CLADIUS-Bootstrapper** (Somnius/Claudius-Bootstrapper)
- **Beschreibung**: Führen Sie benutzerdefinierte Modelle in Claude Code mit dem Bootstrapper aus, mit lokalen LM Studio-Modellen vom Terminal, aber auch innerhalb des Claude Code-Chat-Tabs in VS Code. Wählen Sie ein Modell, konfigurieren Sie es, starten Sie es.
- **Typ**: Lokal/Offline
- **Modelle**: LM Studio (lokale Modelle)

### 11. **deskfish** (0x11c11e/deskfish)
- **Beschreibung**: Geben Sie Ihrer KI einen eigenen Computer. Schauen Sie zu, wie sie arbeitet. Eine VS Code Extension: Ein Chat-Sidebar, eine Live-Ansicht des eigenen gesandboxten Linux-Desktops des Bots und ein Agent, der mit jedem LLM funktioniert.
- **Typ**: Lokal/Offline
- **Modelle**: Beliebige LLMs

### 12. **BLXCommit-Forge** (Bitslix/BLXCommit-Forge)
- **Beschreibung**: Generieren Sie Git-Commit-Nachrichten direkt aus VS Code Source Control mit einem lokalen/offline AI-Modell über Ollama, LM Studio oder einem beliebigen OpenAI-kompatiblen Endpunkt.
- **Typ**: Lokal/Offline
- **Modelle**: Ollama, LM Studio (lokale Modelle)

## 🌟 OpenRouter-basierte Extensions

### 1. **sk-copilot-ai** (alaminofficial/sk-copilot-ai)
- **Beschreibung**: sk-copilot-ai (VS Code Extension) – KI-gestützte Code-Vervollständigungen in VS Code, basierend auf OpenRouter. Bringen Sie Ihren eigenen API-Key und Ihr Modell – keine Abrechnung durch die Extension.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter-Modelle

### 2. **codenexus-ai** (omarabdiwali/codenexus-ai)
- **Beschreibung**: VS Code Extension, die es Benutzern ermöglicht, verschiedene LLMs mit ihrem Code kostenlos zu verwenden.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter-Modelle

### 3. **ai-chat-vscode** (tharun2565/ai-chat-vscode)
- **Beschreibung**: KI-gestützte VS Code Extension mit React-basiertem Chat-Interface. Fragt Coding-Fragen und erhält Echtzeit-Codevorschläge mit OpenRouter's GPT API.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter-Modelle

### 4. **vscode-extension** (rohit30san/vscode-extension)
- **Beschreibung**: KI-gestützte VS Code Extension mit React-basiertem Chat-UI, Dateikontext über @filename und Codegenerierung mit OpenRouter's Mistral 7B API.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter-Modelle

### 5. **WaitorWaitorSlopPlease** (tfritzy/WaitorWaitorSlopPlease)
- **Beschreibung**: VS Code Extension mit einem Befehl, der eine Slop-Edit-Anfrage an die aktuelle Datei mit OpenRouter sendet.
- **Typ**: Cloud-basiert
- **Modelle**: OpenRouter-Modelle

## 📋 Zusammenfassung der Kategorien

1. **Lokal/Offline-Modelle**: Alle Extensions mit Ollama oder LM Studio
2. **Cloud-basiert mit kostenlosen Modellen**: OmniCopilot, FreeCoder, codenexus-ai
3. **OpenRouter-basiert**: sk-copilot-ai, WaitorWaitorSlopPlease, git-commit-planner, onthreg-vscode-extension

## 🎯 Empfehlungen

- **Für Offline-Nutzung**: Nutzen Sie Ollama-basierte Extensions wie `ace-codex`, `Autocomplete-VsCode-Ollama` oder `VSCode-Local-Copilot`
- **Für kostenlose Cloud-Optionen**: Versuchen Sie `OmniCopilot`, `FreeCoder` oder `codenexus-ai`
- **Für LM Studio**: Installieren Sie `vscode-lmstudio` oder `lmstudio-assistant-vscode`
- **Für Google-Gemini**: Verwenden Sie `vscode-continue-google-ai-stuido`
